## Default Permission

### Default Permissions

This permission set configures what kind of
database operations are available from the sql plugin.

### Granted Permissions

All reading related operations are enabled.
Also allows to load or close a connection, and to run, cancel and end
editor sessions (QueryDen's query console).

#### This default permission set includes the following:

- `allow-close`
- `allow-load`
- `allow-select`
- `allow-run`
- `allow-cancel`
- `allow-end-session`
