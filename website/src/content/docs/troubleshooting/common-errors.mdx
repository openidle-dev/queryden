If your error isn't here yet, open an issue with the exact message, the engine, and your OS. The list grows by reproduction.

## Connection

### `connection refused`

The database isn't listening on the host/port you provided, or a firewall is blocking. Verify with `telnet host port` or `nc -zv host port`.

### `password authentication failed for user "..."`

Wrong password, or the database isn't configured to accept password auth from your IP. Check `pg_hba.conf` for PostgreSQL.

### `server version mismatch` (psql / pg_dump)

The [psql console](/docs/editor/psql-console) uses the newest `psql` installed on your machine. A newer client talks to older servers, so install a client at least as new as your newest server; **Settings → CLI Tools** shows which one QueryDen found.

### `psql not found`

Install the PostgreSQL client (the dialog lists the command for your OS) and press **Check Again** — no restart needed. QueryDen also finds `psql` in the standard install folders when they aren't on your `PATH`.

## Vault

### `vault refuses to load on this machine`

By design. The vault is bound to the machine fingerprint. Copying `vault.json` to a different computer makes it unreadable, even with the right password. See [Vault internals](/docs/security/vault-internals).

### `Stored connections or credentials could not be read`

A data file failed to decrypt — usually because the app data folder was copied from another machine. QueryDen leaves the file untouched and won't save over it. Restore the original folder, or move your connections with **Import / Export Connections** instead (see [The vault](/docs/getting-started/vault-setup#moving-to-a-new-machine)).

## Editor

### `Ctrl+D toggles the explorer when I wanted multi-cursor`

Fixed in [#13](https://github.com/openidle-dev/queryden/issues/13). The Database Explorer toggle moved to `Ctrl+Shift+E`, leaving `Ctrl+D` to Monaco's built-in "add selection to next occurrence" multi-cursor.

### No autocomplete suggestions

Completion uses the schema of the tab's connection and database. Open the database in the explorer (tabs on other servers load theirs in the background) and use **Refresh Schema** after DDL changes. See [Completion and navigation](/docs/editor/code-intelligence).

## Performance

### `EXPLAIN runs but the visualizer hangs`

Plans with thousands of nodes (10k+) can stall the visualizer. Open an issue with the plan JSON; we have a known optimization queued.

### Cold start is slow

Cold start should be under a second on modern hardware. If it's not, the most common cause on Linux is missing WebKitGTK env vars — see [Build from source](/docs/getting-started/install#system-requirements).
