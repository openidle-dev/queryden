Every result grid — in a query tab and in Multi Query — has an **Export data** menu above it. Pick a format, choose where to save, and a confirmation appears briefly in the corner.

## Formats

| Format | Details |
|--------|---------|
| **Excel (.xlsx)** | A real Excel workbook, written natively — opens in Excel, LibreOffice and Google Sheets. Bold, frozen header row, columns sized to their content, numbers and booleans stored as numbers and booleans (large integers and high-precision decimals stay exact as text). The sheet is named after the table. |
| **CSV** | RFC 4180: values with commas, quotes or line breaks are quoted, quotes doubled, CRLF line endings. |
| **JSON** | An array of row objects, pretty-printed. |
| **XML** | One `<row>` element per row, column names made into valid XML element names, values escaped. |
| **HTML** | A `<table>` with escaped values — paste into a document or email. |
| **SQL INSERT** | One `INSERT` per row, with identifiers and values quoted for the connection's dialect. |

Choose which formats appear in the menu under **Settings → Import/Export**.

## Generate SQL from rows

Select rows in the grid (or right-click a single row), then right-click → **Generate SQL** and pick a statement type. The **Generated SQL** window shows the result; switch types with the tabs along its top, then press **Copy**.

| Type | What you get |
| --- | --- |
| SELECT | One `SELECT` listing the result's columns from its table |
| SELECT by Unique Key | A `SELECT` per row, matched on its primary key |
| INSERT | An `INSERT` per row |
| UPDATE | An `UPDATE` per row setting every non-key column, matched on the primary key |
| DELETE by Unique Key | A `DELETE` per row, matched on its primary key |
| MERGE / UPSERT | `INSERT … ON CONFLICT (key) DO UPDATE` on PostgreSQL, Supabase, CockroachDB and SQLite; `INSERT … ON DUPLICATE KEY UPDATE` on MySQL and MariaDB |
| DDL | The table's `CREATE` statement (SQLite also lists its indexes and triggers) |

Rows are matched on the table's primary key. When none is known, every column is used, with `IS NULL` for NULL values, so the statements still match exactly the rows you selected. MERGE needs a primary key on every engine except MySQL/MariaDB.

Settings at the bottom of the window are remembered:

- **Use fully qualified names**: write `schema.table` (the database name on MySQL, `main` on SQLite).
- **Compact SQL**: one line per statement.
- **Exclude auto-generated columns**: leave serial / identity, AUTO_INCREMENT, CockroachDB `unique_rowid()`, generated columns and SQLite's `INTEGER PRIMARY KEY` out of INSERT and MERGE.

Binary values are written as hex: `'\x…'` on PostgreSQL-family engines, `X'…'` on MySQL, MariaDB and SQLite.

## Copy

`Ctrl+C` copies the selected cells as tab-separated text, ready to paste into a spreadsheet.
