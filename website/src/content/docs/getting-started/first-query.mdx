## 1. Add a connection

`New connection → pick engine → fill the host / port / user / database`. Optional SSH tunnel for jump-host setups. Connections are stored encrypted and locked to this machine (see [The vault](/docs/getting-started/vault-setup)).

Double-click the connection in the Database Explorer to connect and expand it, then double-click a database to open its schemas. Each connected server keeps its own tree.

| Engine | Notes |
|--------|-------|
| PostgreSQL | Native driver (patched `tauri-plugin-sql`). Each tab is its own session, and values print exactly as `psql` shows them — `numeric`, `interval`, arrays, `infinity` included. |
| MySQL / MariaDB | One driver. MariaDB is supported through the MySQL wire protocol — the same driver as MySQL. Standard types + JSON. |
| SQLite | File-path connection. Multiple DB files per project. |
| CockroachDB | Supported through the PostgreSQL wire protocol — connect with the PostgreSQL driver. No separate backend. |
| Supabase | PostgreSQL plus a connection-string helper for Supabase's hosted format. Under the hood it uses the PostgreSQL driver. |

## 2. Open a tab

`Ctrl+N` opens a new query tab in the current connection. Tabs persist across app restarts — locally, never synced.

## 3. Write and run

```sql
SELECT u.email AS customer, count(o.id) AS orders, sum(o.total) AS total
FROM users u
JOIN orders o ON u.id = o.user_id
GROUP BY u.email
ORDER BY total DESC
LIMIT 10;
```

Hit **`Ctrl+Enter`** to run.

QueryDen parses the buffer and runs only the **statement under your cursor** — not the whole file. If you have 30 statements in the tab, the cursor decides which one fires. This is the single most-loved shortcut in the editor.

To run several statements, select the range first, then `Ctrl+Enter`. `Ctrl+Shift+Enter` runs every statement in the tab.

## 4. What you see next

- A **results grid** appears below the editor with one row per matched record. Glide Data Grid; scrolls smoothly at 100k+ rows.
- A **status line** at the bottom: row count, execution time, and whether a transaction is open in this tab.
- `RAISE NOTICE` output and other server messages under **Messages → Server output**.
- If you ran `EXPLAIN ANALYZE` (or opened the **Optimizer**), the plan tree renders as a visual viewer — hot nodes highlighted, cost percentages shown, one-click "suggest index" via your configured AI provider.
