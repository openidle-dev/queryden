QueryDen ships native installers built by GitHub Actions from the public source tree. Pick your OS on the [download page](/download) or the [GitHub release](https://github.com/openidle-dev/queryden/releases/latest):

| Platform | File | Size |
|----------|------|------|
| macOS (Intel + Apple Silicon) | `QueryDen_<version>_universal.dmg` | ~20 MB |
| Windows (x86_64) | `QueryDen_<version>_x64-setup.exe` | ~6 MB |
| Linux (.deb) | `QueryDen_<version>_amd64.deb` | ~9 MB |
| Linux (AppImage) | `QueryDen_<version>_amd64.AppImage` | ~80 MB |

The macOS build is a single universal binary, so the same `.dmg` runs on Intel and Apple Silicon Macs (releases up to 1.0.23 shipped an Apple Silicon-only `_aarch64.dmg`). The AppImage bundles its own runtime, which is why it's larger; use the `.deb` if your distribution supports it.

## Verify the download

Every installer ships with a matching `.sha256` next to it on the GitHub release page. Run the matching command for your OS and compare the output with the published hash.

```powershell
# Windows (PowerShell)
Get-FileHash QueryDen_<version>_x64-setup.exe -Algorithm SHA256
```

```bash
# macOS / Linux
shasum -a 256 QueryDen_<version>_universal.dmg
sha256sum QueryDen_<version>_amd64.deb
```

If the hashes don't match, don't run the installer — open an issue.

## System requirements

- **macOS** 11 Big Sur or newer, Intel or Apple Silicon.
- **Windows** 10 1809 or newer, x86_64. The WebView2 runtime is installed by the setup `.exe` if it's missing.
- **Linux** glibc 2.35+ (Ubuntu 22.04+, Debian 12+, Fedora 36+) and `webkit2gtk` 4.1.

Optional: a PostgreSQL client (`psql`) for the [psql console](/docs/editor/psql-console). QueryDen finds it on your `PATH` or in the standard install folders.

## Updates

Installed builds update themselves: QueryDen checks the signed release feed and offers the update in-app. To get fixes before they're tagged, see the [beta channel](/docs/getting-started/beta-channel).

## Build from source

```bash
git clone https://github.com/openidle-dev/queryden.git
cd queryden
npm install
npm run tauri build
```

Full instructions live in [the repo's README](https://github.com/openidle-dev/queryden#building).
